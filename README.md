По заданиям было создано 5 Python-файлов, каждый отвечает за одно задание:

(Среднее 1, задание 6) primegenerator.py: Генератор простых чисел. Содержит функцию generate_primes(), которая с помощью yield выдаёт простые числа до указанной пользователем границы включительно.

(Среднее 2, задание 8) timer.py: Декоратор замера времени работы функции. Содержит декоратор measure_time(), который измеряет время выполнения функции с помощью perf_counter(). Работа декоратора демонстрируется на функции sum_squares(), вычисляющей сумму квадратов чисел.

(Среднее 3, задание 2) evenfilter.py: Фильтрация чётных чисел из списка. Содержит функцию filter_even(), которая с помощью filter() и lambda возвращает список чётных чисел.

(Повышенное 1, задание 4) filterfile.py: Фильтрация данных из файла через генератор. Содержит функцию filter_numbers_from_file(), которая построчно читает файл numbers.txt и с помощью yield выдаёт числа больше заданного пользователем порога. Пустые строки пропускаются, некорректные данные обрабатываются с выводом сообщения.

(Повышенное 2, задание 10) reduce.py: Собственная реализация reduce. Содержит функцию my_reduce(), которая последовательно объединяет элементы итерируемого объекта с помощью переданной функции. Поддерживает начальное значение и обработку пустой последовательности. Работа демонстрируется на вычислении суммы и произведения чисел.

Дополнительный файл numbers.txt содержит исходные данные для фильтрации. Он должен находиться в одной папке с filterfile.py.
Для выполнения заданий нужно запустить соотвествующий файл.
